# Page discussions preview

Synthetic clients and workspace users in the locally built Bloomsi Worker. A compact Comments control opens page discussions with attributed replies, readable paragraph spacing, Open/Resolved filtering and resolve/reopen. Can comment is an explicit Share permission inherited by subpages; it never grants document editing or sharing authority. Viewers can read existing discussions.

Interaction reference: [Notion page discussions and comments](https://www.notion.com/help/comments-mentions-and-reminders). This slice covers document-level discussions. Inline text anchors, mentions, notifications and full Notion parity remain separate.

The browser check covers posting/replying, lost-response duplicate-safe retry, stale revision recovery, revoked access and retained unsent text, safe plain text, keyboard/focus and five viewport widths. No real client received a share, invitation or notification. This is a local visual preview, not a deployment. BUILD_STATE owns acceptance and the independent review result.
