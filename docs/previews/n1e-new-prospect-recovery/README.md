# New prospect recovery

Local built-Worker verification on 14 September 2026, using isolated synthetic records. This change is not merged or deployed. [Desktop](creation-receipt-1440.png), [phone](creation-receipt-390.png), and [narrow phone](creation-receipt-320.png) show recovery after a creation succeeded but its reply was lost.

New prospect forms keep incomplete input and the original creation request ID in browser-local copies scoped to the initiating user, workspace and writer. Recovery initially shows only field counts/dates. Reviewing a copy checks current management authority before revealing fields. Creation remains explicit. If the original request already created a prospect, recovery links to that saved record and retains subsequent input for review/download without creating another record.

The existing seven-day, ten-copy and 256KiB limits apply. A replacement copy must be stored successfully before its verified source is conditionally removed; quota failures retain the source. Logout invalidates open forms and clears copies; workspace changes keep the original workspace's copies available on return. Account replacement remounts the form. Copies do not synchronize across devices and browser storage removal can remove recovery data.
