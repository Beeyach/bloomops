# Shared document formatting preview

Locally built Bloomsi Worker with synthetic workspace/client accounts. The existing rich editor saves supported source HTML; authorized read-only clients receive derived safe markup. Native keyboard/touch toggles, responsive three-column content, callouts, headings/marks, read-only tasks, tables/code, inline raster images and equations now render in the shared document reader.

- [Desktop document](document-desktop.png)
- [Mobile document](document-mobile.png)

The39 browser checks exercise actual editor round trips and reloads, client rendering, image picking/re-encoding, keyboard toggles, serialized comparison/matrix equations, five widths, preserved source/revision, unsafe-markup removal, revocation and no editor runtime in reader-loaded scripts. Synthetic image and bookmark references only; external browser/Worker egress is intercepted. Bookmarks remain links; iframe/video activation and video tests remain paused. No attachment storage, document imports or anonymous publication is added. These are local captures, not a deployment; BUILD_STATE owns acceptance.
