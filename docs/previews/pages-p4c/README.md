# P4C Pages sharing preview

Synthetic local built Worker accounts, using the existing Bloomsi shell and document editor. Native SVG page icons, a Share dialog, named view/edit access, inherited subpage permissions, explicit restriction/revocation, and client-portal Pages. Keyboard and1440/1024/768/390/320px layouts are checked. The authenticated link asks before switching workspace; possessing the link grants no access.

The interaction reference is [Notion sharing and permissions](https://www.notion.com/help/sharing-and-permissions). This is named workspace/client sharing, not full Notion parity. Owners/Admins always manage pages; recipients cannot reshare or rearrange them. No anonymous publication, external guest setup or invitation emails are added here. Future comments and wider content compatibility remain separate.
