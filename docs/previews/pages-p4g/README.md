# Page linking preview

Type @ in a Bloomsi page to search your accessible pages and insert a labelled link. The picker supports keyboard navigation, touch, scrolling through results and Escape. Links use the existing shared-page resolver; choosing or receiving one never grants destination access.

- [Desktop](links-desktop.png)
- [Mobile](links-mobile.png)
- [Small mobile](links-small-mobile.png)

Local built Worker and synthetic accounts/documents only.27 browser checks cover insertion, reload, text after links, URL detection, five widths, client touch selection, private suggestion omission, actual reader click-through and revoked destinations. These captures are local, not deployed. BUILD_STATE owns final acceptance and remaining scope.
