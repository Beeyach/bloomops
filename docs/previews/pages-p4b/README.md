# P4B Pages visual preview

Local built Worker with a synthetic workspace; no real documents copied. Bloomsi keeps its existing logo, shell, palette and editor while following familiar [Notion subpage navigation](https://www.notion.com/help/create-a-subpage): expandable pages, a plus beside the parent, breadcrumbs and drag-to-nest. A searchable Move page dialog also supports keyboard/touch and explicit sibling position. The inherited five-level limit remains; full Notion parity is not claimed.

Reviewed at1440,1024,768,390 and320px. Mobile has a labelled collapsible navigator,44px page actions and wrapping document titles. The remote Bloomlab reference could not be retrieved in this session; the committed design system/checklist and existing local Bloomsi surfaces were used.
