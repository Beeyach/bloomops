# Prospect profile recovery

Local built-Worker acceptance with isolated synthetic records, 14 September 2026. This change is not yet merged or deployed. [Desktop conflict review](conflict-1440.png), [phone](conflict-390.png), [narrow phone](conflict-320.png), and [ten-copy limit on phone](recovery-390.png).

The four existing profile editors retain incomplete fields and original source/revision information in separate browser copies. Reload offers metadata first; reviewing a copy checks the current initiating user, workspace, membership and prospect before revealing it. Saving remains explicit. Failed replies retain the draft, an already-applied save is confirmed without a duplicate write, and conflicts preserve both the draft and a review of the saved values. Download or deliberate discard remain available.

Copies are browser-local, scoped to one user/workspace/prospect, limited to ten copies, seven days and256KiB each. Storage failures are reported without preventing an authorized save. Logout clears copies and invalidates other tabs. Workspace changes invalidate mounted editors while retaining the original scope's copy. A disposed editor cannot recreate copies; conditional removal preserves another tab's newer source copy. Browser storage removal and cross-device synchronization are outside this feature.
